# LXMF golden vectors

`golden.json` contains wire-format test vectors generated by the Python
LXMF reference implementation. The Rust test-suite (`tests/golden.rs`)
reproduces them byte-for-byte from the same inputs.

Regenerate with:

```sh
PYTHONPATH=/path/to/Reticulum:/path/to/LXMF python3 fixtures/generate.py
```

Requirements: Python 3 with the `cryptography` module installed (used by
RNS).

## Determinism

* Message vectors (packed bytes, hashes, signatures), the packed
  container, peer data and announce app-data are fully deterministic:
  identities, timestamps, titles, contents, fields and stamps are fixed
  values. The fixed identities are the ones from
  `Reticulum/tests/identity.py`.
* Stamp vectors are the result of hashcash search from a fixed message id,
  so they are stable for a given `LXMF`/`RNS` version, but will change if
  the stamp parameters change.
* The paper message URI, paper/propagation ciphertexts and transient ids
  contain fresh ephemeral keys, so they change on every run. The Rust
  tests only use them as parse/decrypt inputs, never as reproduction
  targets.
